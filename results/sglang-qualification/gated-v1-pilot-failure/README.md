# 完整适配器首次实机启动失败

该工程检查尝试在第一个正式训练用例上运行原生 A/A 和一次计时。第一个资格作业在初始化时失败，后两个作业没有提交，模型调用和留出评估均为零。

完整 gated-v1 源包中的观察器读取了 `Scheduler.max_total_tokens`，而该固定 SGLang 版本使用 `max_total_num_tokens`。这一问题出现在完整配置适配器；此前三容量原生资格探针使用各自固定的源码和正确字段。进程正常被外层回收，回执记录无残留 GPU 进程，不存在可报告的性能结果。

原始失败包、客户端回执、计划和准确源码 ZIP 一同保留。修复必须在新源码版本中进行，再重新取得容量资格和每个正式用例的原生 A/A。旧源和失败回执不改写、不重发。
